# Стиль текста на обложках для статей по турецким сериалам

Этот файл фиксирует утверждённый стиль оформления текста на главных обложках статей проекта «Турок» (канал на Дзене).

## Основные правила

- **Шрифт**: жирный белый санс-сериф (без засечек), чистый современный шрифт в стиле Montserrat / Helvetica / Inter.
- **Выравнивание**: весь блок текста выравнивается по **левому краю** изображения.
- **Подложка**: тёмный полупрозрачный градиент (чёрный или тёмно-синий) под текстом для читаемости.
- **Расположение**: нижняя треть обложки (lower third).
- **Цвет текста**: чистый белый.
- **Стиль**: профессиональный магазинный формат обложки, без лишних элементов и водяных знаков.
- **Метаданные**: обязательно удалять все EXIF/метаданные и метки ИИ перед загрузкой.

## Пример промпта для генерации

> Replace or add elegant bold white sans-serif font (no serifs, clean modern typeface like Montserrat or Helvetica style). Align the entire title text block to the left side of the image. Keep the dark semi-transparent gradient overlay behind the text for readability. Title text exactly: "[НАЗВАНИЕ СТАТЬИ]". Keep the actor and background intact. Professional magazine cover style, high quality, no other text.

## Примечания

- Этот стиль обязателен для всех последующих главных обложек статей по турецким сериалам.
- Дата фиксации стиля: 2026-11-12.
- Утверждённый вариант: левое выравнивание + sans-serif.
